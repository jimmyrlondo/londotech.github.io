Share a set with the band

One file holds the set and every chart in it. Send it by text or email; your bandmates open it here with "Open files" in the Add tab. No accounts, nothing uploaded. The newest copy of each song wins, so the leader's key changes come through.

What it's for

Chord charts and set lists for a worship team or a gigging band. Keep each song once, build sets, change keys for a singer, and play from a big stage view with a foot pedal.

Songs

Paste a chord sheet (chords above the words is fine) or a ChordPro file in the Add tab. Chords are kept in the song's key. Change the key above the chart and every chord moves, spelled right for the new key (sharps in E, flats in Eb). Edit opens the text: [G] puts a chord before a word, [Chorus] on its own line names a part.

Capo

Pick a capo above the chart and it shows the shapes to play: a song in A with capo 2 is played with G shapes. The Capo tab ranks every capo by how easy the shapes are near the nut.

Numbers

Numbers shows the chart as Nashville numbers (1, 4, 5, 6m), counted from the key's home note. They don't change when the key does, so the band can follow a last-minute key change.

Sets

Make a set in the Sets list and add songs. Each song in a set has its own key and capo, so the library song stays as it is. Drag rows to reorder (or use the arrows). Times add up as you go, from each song's length or a guess from its tempo. Tick Segue when a song runs straight into the next, and the key-flow notes warn about awkward jumps and suggest a chord to lead in with.

On stage

Stage shows big text in the set's keys. Auto-scroll paces itself to the song's length. Projector opens a second window with just the words, one part at a time, for a screen or TV; it follows where you are.
