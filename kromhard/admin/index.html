Delete this product line?

This removes it from the live catalog immediately. This can't be undone from here.

Import / Seed Catalog (JSON)

Upload a JSON file (an array of product-line objects matching the catalog schema). Matching IDs are updated in place; new IDs are created. Nothing is deleted.

Import Rows (CSV)

Your spreadsheet's columns must be in the same left-to-right order as the Columns section above (the first row of your CSV is treated as a header and isn't checked, it's just for your own reference). The first column must be the size. A size that already exists gets updated with your new values; a size that doesn't exist yet gets added as a new row. Nothing is saved to the live catalog until you also click Save.
