Compiled Catalogs

A custom or print-ready selection of products and sizes, pulled from any catalog, for printing and binding as its own booklet.

Pick a compiled catalog from the list

Or click "+ New Compiled Catalog" to start one. Give it a name like "Acme Corp Catalog" or "Threading Tools Booklet", then add whichever products and sizes belong in it, from any category or catalog.

Delete this product line?

This removes it from the live catalog immediately. This can't be undone from here.

Import a JSON File

Use this for a file from somewhere else (a spreadsheet export, a file someone emailed you, etc). To update from this site's own data, use "Re-sync from Site Data" instead, no file needed. Upload a JSON file here (an array of product-line objects matching the catalog schema). Matching IDs are updated in place; new IDs are created. Nothing is deleted.

Import Rows (CSV)

Your spreadsheet's columns must be in the same left-to-right order as the Columns section above (the first row of your CSV is treated as a header and isn't checked, it's just for your own reference). The first column must be the size. A size that already exists gets updated with your new values; a size that doesn't exist yet gets added as a new row. Nothing is saved to the live catalog until you also click Save.
